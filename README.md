🏧 ATM Simulation System Using Python

📌 Project Overview

This project is a simple, menu-driven ATM (Automated Teller Machine) simulation developed using Python. It allows users to perform basic banking transactions through a command-line interface.

The program includes card insertion, PIN verification, account number entry, cash deposits, cash withdrawals, and balance inquiries.

✨ Features

Card Verification: Prompts the user to insert a card before proceeding.

PIN Authentication: Verifies the user's four-digit PIN.

Personalized Welcome: Displays a welcome message after successful PIN verification.

Account Number Entry: Requests the account number only once per ATM session.

Cash Deposit: Allows users to deposit money into their account.

Cash Withdrawal: Allows users to withdraw money, with insufficient-balance validation.

Balance Inquiry: Displays the current account balance.

Input Validation: Checks transaction amounts to prevent invalid deposits and withdrawals.

Continuous Transactions: Allows users to perform multiple transactions in a single session.

Transaction Exit: Displays a thank-you message when the user exits.
